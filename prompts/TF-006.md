## My Assessment

  Here is what each part of that message means.

  1. "pose and pass fire only in an intransitive, reflexive or "off" as frame"

  DISGUISE_METAPHOR looks for something described as disguised as something else. The
  old code counted pose and pass as disguise verbs on their own, with no frame needed.
  The new code fires on them only when they have an as phrase and take one of three
  shapes:

  - intransitive: no object, as in A rewrite posing as a refactor. The subject itself
    is the impostor.
  - reflexive: the only object is a -self word, as in Speculation passing itself off as
    evidence.
  - with off: as in a rewrite passed off as a refactor. This is the one passive form
    allowed, because passed off as is the idiom for disguise.

  2. "literal posing challenges, passing tests and passive "passed as an argument" no 
  longer fire"

  These are the false positives the fix removes:

  - No as at all: posing significant challenges, passing all regression tests, message 
    passing. This was most of the arXiv findings.
  - as with an ordinary object: passing the depth as an argument, passing it as an 
    argument. Something is handed over in a role, not disguised.
  - Passive as without off: The value is passed as an argument, The problem is posed as
    an integer program. These are common in hardware and software papers. An as check
    alone would have kept them, so they needed their own rule.

  3. "pass for left out (literal in test prose)"

  Guesswork passing for analysis. is a disguise use, but The test is passing for all 
  seeds. has the same grammar and is literal. Verification writing, including the
  pacino blogs, uses the second kind constantly, so supporting pass for would bring
  false positives back. A negative row guards against it being added later.

  4. "14 new test rows"

  3 positive rows and 11 negative rows in tools/tests.py. 7 of the negative rows failed
  on the old code. The other 4 were already silent, because the detector only looks at
  -ing and -ed forms, so pose/passes as plain verbs never fired anyway.

  5. "New eval/arxiv_recheck.py reruns stored arXiv findings under old and new 
  detectors"

  The script takes the stored DISGUISE_METAPHOR findings from TF-004 and TF-005 and
